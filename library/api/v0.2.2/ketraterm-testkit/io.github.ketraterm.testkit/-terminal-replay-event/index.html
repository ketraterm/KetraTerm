TerminalReplayEvent

sealed interface TerminalReplayEvent

One deterministic operation in a headless terminal replay.

Input events preserve transport chunk boundaries: every Input is delivered to the parser by one accept call. Resize and end-of-input events remain in the same ordered stream, allowing transcripts to reproduce timing-sensitive parser, reflow, and flush behavior without a PTY.
