TerminalCompletionMatchRanges

class TerminalCompletionMatchRanges

Immutable ordered match ranges relative to one completion display string.

Ranges use UTF-16 offsets and are stored as packed primitive pairs internally. Every range is non-empty, ranges are ordered and non-overlapping, and endpoints are Unicode-scalar boundaries that do not split surrogate pairs. The empty instance is shared; non-empty factories defensively copy caller-owned arrays.
