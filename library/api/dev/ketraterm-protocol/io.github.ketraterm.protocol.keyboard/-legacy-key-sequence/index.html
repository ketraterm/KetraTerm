LegacyKeySequence

object LegacyKeySequence

Fixed legacy keyboard wire vocabulary shared by capability discovery and input encoding. Strings contain actual control bytes, not terminfo source escapes. They describe unmodified keys except BACK_TAB; extended keyboard formats have separate vocabulary.
