TerminalColorRequest

class TerminalColorRequest(capacity: Int)

Reusable, ordered OSC 21 operations with borrowed original key bytes.

A producer fills this batch before synchronous delivery. Consumers must not retain or mutate it or its source bytes. Queries observe preceding operations and contribute to one reply in request order. Numeric targets are indexed colors in 0..255; named targets and operations use the constants below.

Storage is allocated once. capacity bounds the number of nonempty fields; it does not impose a wire payload limit, which belongs to the parser.
