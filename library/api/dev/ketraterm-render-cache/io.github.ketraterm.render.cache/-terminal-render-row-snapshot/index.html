TerminalRenderRowSnapshot

class TerminalRenderRowSnapshot : TerminalRenderFrame

Immutable primitive copy of one physical terminal row, including colors, cell styles and clusters. Capturing allocates; subsequent copies never read or retain the source frame. No cursor, images, terminal hyperlinks, or viewport policy are retained. Consumers may share this value.

Each snapshot is an independent content source with constant generations, even when two snapshots preserve the same lineId. Call TerminalRenderCache.reset before passing a different snapshot to TerminalRenderCache.accept; generations cannot be compared across snapshot instances. Row access uses index zero, regardless of the original source row.
