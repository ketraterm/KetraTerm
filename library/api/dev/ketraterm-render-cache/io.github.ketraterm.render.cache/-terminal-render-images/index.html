TerminalRenderImages

class TerminalRenderImages

Copied placement metadata in stacking order. Owned by a TerminalRenderCache; access has the same confinement/lease lifetime as that cache. Resources alone are immutable and retainable. Destination geometry uses fractional viewport cells; source crops use image pixels, as defined by TerminalRenderImageSink. Indexed reads require index in 0 until size and throw IllegalArgumentException otherwise. An update replaces this borrowed set, even when resources are reused.
