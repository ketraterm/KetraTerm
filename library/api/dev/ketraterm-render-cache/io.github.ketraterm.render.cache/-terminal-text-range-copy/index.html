TerminalTextRangeCopy

class TerminalTextRangeCopy(val maxRows: Int = 64, val maxCells: Int = 4096)

Worker-confined, reusable text-only copy of a bounded absolute row range.

Only primitive copying occurs inside the reader callback. Arrays are borrowed until the next read; only rows times columns cells are active. Every active code/flag entry is overwritten, so spare capacity needs no clearing. Cluster references are meaningful only for cells with the CLUSTER flag and a nonzero reference.

Bounds and cancellation have the same meaning as TerminalRenderRangeCopy. Failed or empty reads leave rows zero; partially copied arrays must not be consumed.
