TerminalRenderRangeCopy

class TerminalRenderRangeCopy(val maxRows: Int = 64, val maxCells: Int = 4096)

Worker-owned primitive copy of an absolute source range, reusable across reads.

Only row/cell copying occurs in the reader callback (and any session mutation lock); string assembly and analysis use cache after read returns. Each read copies at most maxRows and maxCells, except that one physical row is always permitted when wider than the cell budget. Cluster payloads copy with that row. The cache and bounds remain owned by this instance until the next read.
