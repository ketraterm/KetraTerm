TerminalShellCommandInventory

class TerminalShellCommandInventory(commands: List<TerminalShellCompletionCandidate>, val status: TerminalShellCommandInventoryStatus = TerminalShellCommandInventoryStatus.READY)

Detached, immutable command availability from one shell environment. READY carries verified commands; additional independent sources may still be discovering. Only TerminalShellCommandInventoryStatus.READY carries commands. Other states offer no verified candidates and must not enable unverified catalog fallback. Construction validates aggregate retained text, shares identical insertion/name strings, and builds the sorted prefix index and alias lookup once.

commands is borrowed only during construction. Duplicate names are rejected. Records must be commands with empty descriptions, nonempty control-free names and insertions, and bounded literal alias definitions. See MAX_COMMANDS and MAX_TEXT_LENGTH for aggregate bounds; invalid input throws IllegalArgumentException. This snapshot carries no editing authority and does not execute alias definitions.
