ketraterm-core

The headless state engine. Semantic writer, cursor, and mode operations mutate primary or alternate screen state; readers expose that state through public core roles and primitive render frames.

ketraterm-host
Link copied to clipboard

Parser-to-core command mapping and host-control policy for the terminal pipeline. The public package is io.github.ketraterm.host.

ketraterm-input
Link copied to clipboard

Host-bound encoding for platform-neutral input events. The public facade reads core input modes and writes through TerminalHostOutput; the module neither parses terminal output nor owns a connector.

ketraterm-parser
Link copied to clipboard

Converts ordered terminal host bytes into semantic commands. The public entry points are io.github.ketraterm.parser.api.TerminalParsers and io.github.ketraterm.parser.api.TerminalOutputParser; the destination is io.github.ketraterm.parser.spi.TerminalCommandSink. This module depends only on ketraterm-protocol.

ketraterm-protocol
Link copied to clipboard

Shared protocol vocabulary. Its only production dependency is the Kotlin standard library. The module contains identifiers, semantic values, small validation helpers, and a host-bound byte sink; parsing and terminal behavior remain in their owning layers.

ketraterm-pty

Local PTY process and connector lifecycle, with convenience construction of the shared session runtime. Public APIs live in io.github.ketraterm.pty; the README.md covers host assembly.

ketraterm-render-api

Primitive renderer-facing contracts in io.github.ketraterm.render.api. Its only production dependency is the Kotlin standard library.

ketraterm-render-cache
Link copied to clipboard

Renderer-owned primitive storage and leased publication of copied terminal frames. Its sole production dependency is ketraterm-render-api; synchronization with terminal mutation belongs to the source reader.

ketraterm-session
Link copied to clipboard

The runtime boundary joining transport, parser, core, host mapping, input encoding, and render publication. Public contracts live in io.github.ketraterm.session; the README.md covers consumer assembly.

ketraterm-shell-integration

Optional OSC-based producer for the shell metadata contracts in ketraterm-session. The public package io.github.ketraterm.shell.integration exposes OscShellIntegration and its configuration factory. Session, PTY, and Swing do not depend on this module.

ketraterm-transport-api
Link copied to clipboard

Transport-neutral byte-stream contracts. The only production dependency is the Kotlin standard library. The package io.github.ketraterm.transport contains TerminalConnector, TerminalConnectorListener, and byte-range validation.
