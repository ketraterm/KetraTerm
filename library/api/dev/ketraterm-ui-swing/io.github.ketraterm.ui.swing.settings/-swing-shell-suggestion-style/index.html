Immutable colors for the built-in shell suggestion popup. Custom views own their styling.

Defaults form a dark palette. Every color is a concrete packed ARGB value and is used exactly, without theme lookup, inheritance, or contrast correction during rendering. Text and fills must be opaque; border may have alpha, including zero to omit its outline. Apply changed settings with io.github.ketraterm.ui.swing.api.SwingTerminal.reloadSettings.

Throws

IllegalArgumentException

if a non-border color is translucent.
