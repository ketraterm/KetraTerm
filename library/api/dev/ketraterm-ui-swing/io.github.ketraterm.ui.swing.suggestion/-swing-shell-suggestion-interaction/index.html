SwingShellSuggestionInteraction

class SwingShellSuggestionInteraction(val request: SwingShellSuggestionRequest, handler: SwingShellSuggestionHandler = SwingShellSuggestionHandler.NONE, feedbackHandler: SwingShellSuggestionFeedbackHandler = SwingShellSuggestionFeedbackHandler.NONE) : AutoCloseable

One suggestion request shared by built-in, detached Swing, and IntelliJ presentation.

Construct and call on the EDT. The owner captures handler before asynchronous work, publishes immutable candidate snapshots, and closes obsolete requests. Views own mounting, placement, and visibility; they invoke guarded operations instead of reporting acceptance. Provider completion does not close a still-usable final publication.

Acceptance leaves the active state before any view callback. The original handler and feedback destination survive reentrant UI replacement. Callback failures propagate, but cleanup completes and an edit or feedback event is never retried.

Parameters

handler

original editing capability; owned and closed by this interaction.

feedbackHandler

original request observer. Passive closure produces no preference feedback.
