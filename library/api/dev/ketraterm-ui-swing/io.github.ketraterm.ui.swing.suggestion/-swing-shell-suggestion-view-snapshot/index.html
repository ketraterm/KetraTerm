SwingShellSuggestionViewSnapshot

class SwingShellSuggestionViewSnapshot

Immutable viewport published to one shell-suggestion view.

The controller retains the complete ranking and sends each renderer only a bounded window. Absolute viewport metadata lets custom-painted and native list implementations expose overflow consistently without duplicating controller state.
