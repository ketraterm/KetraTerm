SwingHostServices

class SwingHostServices

Host-provided non-render services for SwingTerminal.

These services are intentionally kept out of row painters. Rendering consumes immutable settings and render-cache snapshots, while host integrations supply scheduling, clipboard, and explicit hyperlink activation policy here. Use create and copy for selective construction and immutable updates. Service references remain host-owned; building or copying never starts or closes them. View-lifetime services such as suggestion diagnostics use EDT methods on SwingTerminal.
