SwingClipboardReader

class SwingClipboardReader(ioDispatcher: CoroutineDispatcher = Dispatchers.IO)

Window-owned clipboard reader: at most one consent prompt per window and one native read across all instances. Busy requests complete without queuing.

The host must enter the EDT after earlier posted writes and resolve the prompt from the requesting session's pane. The session owns the request deadline and cancellation. A blocked native call retains its slot until it actually returns.
