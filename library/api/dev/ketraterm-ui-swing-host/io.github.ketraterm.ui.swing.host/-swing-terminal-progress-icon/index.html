SwingTerminalProgressIcon

class SwingTerminalProgressIcon @JvmOverloads constructor(size: Int = 16) : Icon, AccessibleIcon

Reusable thin progress ring. Construct, configure and paint on the EDT. Size is in logical Swing pixels, inclusive 8..128. Hidden progress paints nothing. The host owns session observation, icon replacement, repainting and animation; advance phase for indeterminate work, or leave it fixed to disable animation. Colors can be changed by embedders without changing session policy. Painting inherits transform/clip, preserves color/stroke and rendering hints, and reuses shapes/strokes. Java2D/platform rasterization may have its own allocations.
