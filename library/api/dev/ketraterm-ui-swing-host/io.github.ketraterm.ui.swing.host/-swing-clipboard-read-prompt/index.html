SwingClipboardReadPrompt

class SwingClipboardReadPrompt(messages: SwingHostMessages, showDialog: (request: SwingDialogRequest, decide: (Int?) -> Unit) -> AutoCloseable) : AutoCloseable

Cancellable read consent owned by one terminal pane. All operations belong to the EDT. The product presents its standard dialog and returns a handle that closes it. No clipboard content is passed to the dialog.

Cancellation, expiry and pane disposal close the dialog. Blocking persists for this pane's lifetime, including later requests admitted with Allow.
