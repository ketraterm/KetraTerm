TerminalShellLaunch

class TerminalShellLaunch : AutoCloseable

Prepared shell hooks for one host-owned process and session.

Preparation can write startup scripts. Call it off the UI thread before process creation. Pass profile to the process launcher and shellIntegration to the session factory. Call attach before starting the session. Close this handle if startup fails. Close the process and session before closing this handle during normal disposal. This handle never starts or closes a process or a session.

Generated scripts are reusable cache files owned by the host's script directory. Closing this handle removes only its private command inventory mailbox.
