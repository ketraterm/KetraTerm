SwingCompletionBinding

class SwingCompletionBinding(session: TerminalSession, rankingContextKey: () -> String? = { null }) : AutoCloseable

Connects optional host completion resources to one Swing terminal.

Hosts own provider construction and persistence. This binding owns automatic observation and forwards requests only to the current resources. Configure, attach, and close on the EDT. An empty binding starts no coroutine work.
