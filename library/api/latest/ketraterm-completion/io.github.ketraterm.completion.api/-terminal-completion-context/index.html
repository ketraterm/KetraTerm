TerminalCompletionContext

class TerminalCompletionContext

One parsed, spec-resolved completion context shared by every source.

The merged engine constructs this object once per request. Source implementations consume it directly to determine eligibility, prefix matching, replacement ranges, and semantic argument kinds without re-tokenizing the command line.
