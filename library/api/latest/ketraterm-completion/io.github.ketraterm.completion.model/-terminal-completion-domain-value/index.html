TerminalCompletionDomainValue

data class TerminalCompletionDomainValue @JvmOverloads constructor(val value: String, val displayText: String = value, val detail: String = "", val scoreAdjustment: Int = 0)

Immutable host-provided value for one dynamic completion domain.

Suspended host sources return bounded lists of these values. The shared engine then performs prefix matching, replacement-range selection, shell quoting, and ranking without retaining host resources.

Throws

IllegalArgumentException

if value or displayText is blank, or if scoreAdjustment is outside MIN_SCORE_ADJUSTMENT through MAX_SCORE_ADJUSTMENT.
