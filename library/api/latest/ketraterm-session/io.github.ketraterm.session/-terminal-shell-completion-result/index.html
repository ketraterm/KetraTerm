TerminalShellCompletionResult

class TerminalShellCompletionResult @JvmOverloads constructor(val commandLine: String, val cursorOffset: Int, val replacementStartOffset: Int, val replacementEndOffset: Int, candidates: List<TerminalShellCompletionCandidate>, val externalCommandName: String? = null)

Native shell completion for one exact command buffer and UTF-16 cursor. Replacement bounds are inclusive at the start and exclusive at the end. The producer must validate bounds, Unicode, text sizes, and candidate controls before publication. candidates is copied at construction and cannot be mutated. externalCommandName identifies the resolved application after following aliases, or is null for shell commands, functions, scripts, unresolved invocations, or command-name completion. It is argument-completion metadata, never code.
