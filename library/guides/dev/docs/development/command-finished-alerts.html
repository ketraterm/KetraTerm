Command-finished alert verification

Baseline: 1bfaaf9eb, 2026-10-29. The original scoped root suites passed before production edits. New focused regressions first failed compilation because the elapsed-duration query, alert settings, and eligibility policy were absent.

The six native PTY cases retain their existing opt-in guard. This change does not alter shell hooks or PTY behavior. The first plugin baseline stopped from native JVM memory exhaustion before assertions. Final plugin verification used full JetBrains JDK 25 for Gradle and instrumentation. A fresh compilation removed ten stale constructor-linkage failures in the unchanged profile/restore tests; all 267 tests then passed without disabling tests or changing their assertions.

Focused evidence:

  • Duration regressions: clock rollback, nanosecond wrap, bounds, abandonment, eviction, and synchronous capture.
  • Session regressions: initial/live notification permission, closure, and unavailable policy ownership.
  • Shared policy regressions: defaults, inclusive thresholds, overflow, unknown duration, lifecycle, focus, and denial.
  • Standalone callbacks and IDE callbacks: real workspace routing, focus changes, live preferences, revoked session permission, coalescing, slot release, and disposal.

Configuration tests cover legacy defaults, persistence, malformed/overflowing standalone values, normalized IDE bounds, and settings controls. Existing shell marker ordering, malformed/chunked input, duplicate completions, and cleanup regressions remain in the owning suites.

The public session API check passes with additive methods only; metadata constructor/copy signatures and the public shell-state constructors are unchanged. Rendering paths are unchanged; no new per-frame allocation claim is made.

Final checks also passed publishedConsumerTest: independent Java/Kotlin source consumers with Gradle metadata and POM-only resolution, on Kotlin 2.4.20 and 2.4.0, plus all 46 retained-client upgrade cases. Changed Markdown links were checked locally (94 targets).
